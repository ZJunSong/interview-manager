使用文档

快速上手 Interview Manager

快速开始

Windows 桌面版

  • 从下载页面获取安装包
  • 双击 InterviewManager-Setup-x.x.x.exe 运行安装程序
  • 按照向导完成安装
  • 双击桌面图标启动应用

在线 Web 版

  • 访问在线使用页面
  • 注册账号或登录已有账号
  • 开始添加面试记录

功能说明

添加面试记录

点击右上角的 "+" 按钮，输入公司名称和职位，即可创建新的面试记录。

更新面试状态

点击时间线上的当前阶段节点，会弹出操作面板，可以选择：

  • 通过 — 自动推进到下一阶段
  • 未通过 — 标记为失败
  • 跳过 — 跳过当前阶段
  • 拒绝 — 你拒绝了这家公司

搜索和排序

在顶部搜索框输入公司名或职位进行筛选，点击排序按钮可以选择排序方式。

导入导出

支持 JSON 格式的导入导出，方便数据备份和迁移。

键盘快捷键

  • Enter — 确认操作
  • Escape — 取消/关闭
  • Tab — 切换焦点
  • ← → — 切换阶段节点

数据说明

桌面版：数据存储在 %APPDATA%/InterviewManager/data/ 目录下。

Web 版：数据存储在云端服务器，需要登录才能访问。

常见问题

数据会丢失吗？

桌面版数据存储在本地，建议定期使用导出功能备份。Web 版数据存储在云端，相对更安全。

可以在手机上使用吗？

Web 版支持手机浏览器访问。桌面版目前仅支持 Windows 系统。

如何迁移数据？

使用导出功能将数据导出为 JSON 文件，然后在新设备上使用导入功能即可。
