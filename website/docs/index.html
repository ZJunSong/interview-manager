快速开始

Interview Manager 提供两种使用方式：Windows 桌面版和在线 Web 版。选择最适合你的方式开始使用。

Windows 桌面版

桌面版提供完全离线的使用体验，数据存储在本地，无需网络连接。

安装步骤

  1. 从下载页面获取最新安装包
  2. 双击 InterviewManager-Setup-x.x.x.exe 运行安装程序
  3. 按照向导完成安装（默认安装路径即可）
  4. 双击桌面图标启动应用

系统要求

  • 操作系统：Windows 10 / 11（64位）
  • 磁盘空间：200MB 可用空间
  • 无需安装 Node.js 或其他运行时

数据存储位置

数据文件存储在：

%APPDATA%\InterviewManager\data\interviews.json

你可以直接备份此文件，或使用应用内的导出功能。

在线 Web 版

Web 版支持浏览器直接使用，数据云端同步，多设备访问。

使用步骤

  1. 访问在线使用页面
  2. 点击"注册"创建新账号（用户名 + 密码）
  3. 或使用已有账号登录
  4. 开始添加面试记录

账号说明

  • 每个账号的数据完全隔离，互不可见
  • 密码使用 bcrypt 加密存储
  • 登录状态通过 JWT Token 维持
  • 支持同时在多个设备登录

功能说明

Interview Manager 提供完整的面试流程管理功能，从投递到 Offer 全程追踪。

添加面试记录

点击右上角的 "+" 按钮，填写以下信息即可创建新的面试记录：

  • 公司名称（必填）— 内置 35+ 知名科技公司自动补全
  • 职位名称（必填）— 支持常见职位自动补全
  • 投递时间（选填）— 默认为当天

自动补全列表

内置公司包括：字节跳动、阿里巴巴、腾讯、美团、京东、百度、华为、小米、网易、快手、拼多多、滴滴、小红书、B站、蚂蚁集团等。

更新面试状态

点击时间线上的当前阶段节点，会弹出操作面板，提供以下操作：

操作 说明 视觉效果
通过 当前阶段通过，自动推进到下一阶段 绿色圆形 + 白色对勾
未通过 当前阶段未通过，标记为失败 红色圆形 + 白色叉号
跳过 跳过当前阶段（如免笔试） 灰色圆形 + 横线
拒绝 你拒绝了这家公司 红色边框 + 红色叉号

10 个阶段说明

  1. 投递简历
  2. 笔试
  3. 一面（技术面）
  4. 二面（技术面）
  5. 三面（主管面）
  6. HR面
  7. 交叉面
  8. 总裁面
  9. offer沟通
  10. 正式 Offer

搜索和排序

在顶部搜索框输入公司名或职位进行实时筛选。

排序方式

  • 按时间（默认）— 最新投递的排在前面
  • 按名称 — 按公司名拼音排序
  • 按进度 — 面试阶段越靠后越靠前

导入导出

支持 JSON 格式的导入导出，方便数据备份和迁移。

导出数据

点击导出按钮，将所有面试记录导出为 interviews.json 文件。

导入数据

点击导入按钮，选择 JSON 文件，支持两种导入模式：

  • 合并 — 保留现有数据，添加新记录
  • 覆盖 — 清空现有数据，完全替换

数据迁移

桌面版与 Web 版数据格式完全一致，可自由迁移：

  1. 在源设备导出 JSON 文件
  2. 在目标设备导入该文件

键盘快捷键

支持完整的键盘操作，无需鼠标即可完成所有功能。

快捷键 功能
Enter 确认操作 / 打开选中的卡片
Escape 取消 / 关闭弹窗
Tab 在界面元素间切换焦点
← → 在时间线阶段节点间切换
↑ ↓ 在面试卡片列表中移动
Space 打开当前阶段的操作菜单

无障碍支持

  • 所有交互元素支持键盘焦点环
  • 屏幕阅读器可识别所有状态
  • ARIA 标签完整覆盖

数据说明

桌面版数据

  • 存储位置：%APPDATA%\InterviewManager\data\
  • 文件格式：JSON（UTF-8 编码）
  • 自动备份：每次保存前创建 .backup 文件
  • 原子写入：先写临时文件，再重命名，防止数据损坏

Web 版数据

  • 存储位置：云端服务器 SQLite 数据库
  • 每个账号数据完全隔离
  • 支持多设备同步访问
  • 建议定期导出备份

数据安全

  • 写入串行化，防止并发覆盖
  • 临时文件 + 重命名，防止写入中断导致数据损坏
  • 备份文件保留最近状态

常见问题

数据会丢失吗？

桌面版数据存储在本地，建议定期使用导出功能备份到安全位置。Web 版数据存储在云端，相对更安全，但也建议定期备份。

可以在手机上使用吗？

Web 版支持手机浏览器访问，界面自适应移动端。桌面版目前仅支持 Windows 系统。

如何迁移数据？

使用导出功能将数据导出为 JSON 文件，然后在新设备上使用导入功能即可。桌面版与 Web 版数据格式完全一致。

支持哪些浏览器？

Web 版支持所有现代浏览器：

  • Chrome 90+
  • Firefox 88+
  • Safari 14+
  • Edge 90+

如何修改密码？

目前 Web 版暂不支持修改密码功能。如果忘记密码，需要重新注册账号并导入之前导出的数据。

面试记录有数量限制吗？

没有数量限制。桌面版受限于本地磁盘空间，Web 版受限于服务器存储空间，但正常使用不会达到上限。
