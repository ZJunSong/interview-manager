# Icon Files

This directory should contain the application icon in the following formats:

- `icon.png` - Main application icon (256x256 or 512x512)
- `icon.ico` - Windows icon format (for .exe)
- `tray-icon.png` - Small tray icon (16x16 or 32x32)

You can create these icons using:
- [Electron Icon Maker](https://github.com/nicedoc/electron-icon-maker)
- [IconGenerator](https://github.com/nicedoc/icon-generator)
- Or manually create with any image editor

The icon should be:
- Simple and recognizable at small sizes
- Follow your brand colors
- Have a transparent background (for tray icon)
